# Data Relay Engineering System

**ChatGPT owns requirements, design, implementation, testing, coordination, and audit. GitHub is durable authority.**

Owner intent flows into a GitHub AI Work Packet, then ChatGPT implements on an authorized clean worktree, runs deterministic tests, verifies the exact remote HEAD and CI/review state, and merges only verified evidence.

## Default contract

ChatGPT Chat is the default implementer. Conversation history is working context, not authority. The active Work Packet, repository, branch, exact HEAD, CI, and review state determine what may happen next.

Cursor is disabled by default. Compatibility files may remain, but Cursor may run only after an explicit owner reactivation for the current packet and an IMPLEMENTER=CURSOR declaration.

## Core rules

1. GitHub is durable state; chat context is disposable.
2. One bounded workstream uses one active Work Packet.
3. Mutation and terminal PASS require exact identity and clean state.
4. Tests and CI are evidence; agent prose is not.
5. Optional tools stay optional until they solve a real problem.
