# Daily workflow

## 1. Capture owner intent

ChatGPT reads repository rules and current GitHub state, then creates or updates one bounded AI Work Packet with repository, workstream, branch, exact HEAD, risk, implementer, Current State, Next Action, and terminal evidence.

## 2. Implement directly

When the packet authorizes implementation, ChatGPT works in an isolated clean worktree through the approved remote-development path. It does not hand work to or wait for Cursor.

Before mutation, ChatGPT rechecks authenticated packet authority, repository/worktree/branch/HEAD, intent revision, change risk, IMPLEMENTER=CHATGPT_CHAT, and local cleanliness.

## 3. Test from cheap to expensive

Run focused static/unit checks first, then affected integration tests and any required full, release, or platform gates.

## 4. Reconcile exact HEAD

After commit and push, independently verify the remote PR head, CI, actionable review findings, and packet state. Evidence from an earlier commit is stale after HEAD changes.

## 5. Merge and close

Merge only the verified exact HEAD. Re-read the default branch after merge and mark the packet COMPLETE only when its terminal contract is satisfied.

Legacy phrases such as “Cursor 끝났어. 계속” mean “reconcile and continue in ChatGPT”; they do not reactivate Cursor.
