# Data Relay Engineering System

**ChatGPT는 사고와 설계, Cursor는 구현, GitHub는 진실, 개발 서버 직접 감사는 검증을 담당합니다.**

이 시스템은 AI 개발 자체보다 그 주변에서 반복되던 불편을 줄이기 위해 만들어졌습니다.

긴 Cursor 프롬프트, 대화창 Handoff, 오래된 로드맵, 사라지는 설계 이유, 불필요한 Full Suite, 이동 중 터미널 확인 같은 문제를 하나씩 제거하면서 현재 구조가 만들어졌습니다.

~~~

<Note>
  Canonical source of truth는 GitHub입니다. Athena, 이 홈페이지, Telegram, AI Work Packet은 각각 검색·설명·알림·현재 작업 조정을 위한 보조 계층입니다.
</Note>

## 시스템을 작게 유지하는 다섯 가지 규칙

1. GitHub가 normative이고 Handbook과 Athena는 derived layer입니다.
2. ChatGPT는 설계·리뷰, Cursor는 bounded implementation을 담당합니다.
3. 현재 작업에 필요한 context만 읽습니다.
4. Expensive broad qualification 전에 affected deterministic check부터 실행합니다.
5. Session state는 giant handoff prompt가 아니라 repository-scoped Work Packet에 둡니다.

## 핵심 원칙

이 시스템은 하나의 AI에게 모든 일을 맡기지 않습니다.

ChatGPT에서 충분히 대화하면서 요구사항, 아키텍처, 설계, 문서, 테스트 전략과 범위를 먼저 잡습니다. 실제 코드 변경이 필요한 시점에만 Cursor로 넘깁니다.

Cursor가 작업을 마치면 결과를 다시 ChatGPT가 검토하고, 필요하면 Desktop Commander로 개발 서버의 실제 branch, HEAD, dirty state, test, process까지 직접 확인합니다.

<Tip>
  하나만 기억하면 됩니다. **대화는 임시 작업 공간이고, 오래 남아야 할 engineering state는 대화 밖에 둡니다.**
</Tip>
