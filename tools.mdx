# Tool stack

## ChatGPT

The default engineering worker: requirements, design, code and docs changes, tests, GitHub coordination, exact-head reconciliation, and terminal audit.

## GitHub

Durable authority for AI Work Packets, branches and exact SHAs, PRs, review findings, checks, and merge history.

## Remote development tools

Desktop Commander or another approved connector gives ChatGPT controlled access to authorized development worktrees and test environments.

## Cursor

Dormant compatibility only. Do not create, resume, attach to, or wait on Cursor unless the owner explicitly reactivates it for the current packet and that packet records IMPLEMENTER=CURSOR.

## Codex or other independent reviewers

Optional defense-in-depth for high-risk work. They do not replace deterministic tests, exact-head CI, or required human approvals.

## Telegram and Athena

Telegram is informational notification only. Athena is optional knowledge/retrieval support. Neither is implementation authority.
